# Запис про кодингового агента

Обраний інструмент: ChatGPT Codex.

Клас інструменту: кодинговий агент на основі великої мовної моделі.

Спосіб доступу до репозиторію: агент працює з файлами локального репозиторію у робочому середовищі.

Доступні операції: 

 - перегляд структури вмісту файлів;
 - створення і редагування файлів;
 - аналіз змін;
 - виконання Git-команд;
 - підготовка змін до коміту;
 - створення комітів за дозволом користувача;
 - запуск тестів і перевірок.
