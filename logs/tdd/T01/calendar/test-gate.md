# T01 / F007: технічний TEST-GATE

Джерела: REQ-F-027–035, AC-F-027-01–035-01 та додаткові AC-F-032-02/033-02/034-02/035-02–04; BDD-007/008/019/020 лише календарні частини; OpenAPI LocalHour й OP-09/10. Вартість, бронювання та HTTP-виклики залишаються наступним пакетам. Інтеграційна готовність OP-09/10 не заявляється.
