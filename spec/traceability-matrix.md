# Матриця простежуваності з планованими тікетами

Джерела: [функціональні вимоги](functional-requirements.md), [нефункціональні вимоги](non-functional-requirements.md), [критерії прийняття](acceptance-criteria.md), [BDD-сценарії](bdd-scenarios.md) та [SRS](srs.md).

Зв’язки з критеріями взято з їхніх посилань на вимоги; зв’язки з BDD — лише з поля «Пов’язані вимоги». Символ «-» у колонці BDD означає відсутність явного зв’язку. Колонка «Тікет» містить внутрішні ID, номери та реальні посилання планованих GitHub Issues. Колонки «Тест», «Код» і «Документація» не заповнені: виконані артефакти тут не заявляються.

Оновлення: 7 жовтня 2026 року. Планові зв’язки взято зі [скоригованої декомпозиції](../planning/revised-decomposition.md), [залежностей](../planning/ticket-dependencies.md) та [ролей](../planning/roles.md). Відповідність 54 внутрішніх ID реальним Issues наведено в [issue-mapping.md](../planning/issue-mapping.md).

У рядках наведено Feature, Test, Verification, застосовні Specification/Addendum та персональні READY-GATE. Спільні задачі для всіх вимог: [VAL-001 #35](https://github.com/safonovdmitrij/car-rental-system/issues/35), [VAL-002 #36](https://github.com/safonovdmitrij/car-rental-system/issues/36), [DOC-001 #37](https://github.com/safonovdmitrij/car-rental-system/issues/37), [DOC-002 #38](https://github.com/safonovdmitrij/car-rental-system/issues/38), [SPEC-GATE #3](https://github.com/safonovdmitrij/car-rental-system/issues/3), [PLAN-GATE #4](https://github.com/safonovdmitrij/car-rental-system/issues/4), [ACCEPTANCE-GATE #6](https://github.com/safonovdmitrij/car-rental-system/issues/6). [READY-GATE #5](https://github.com/safonovdmitrij/car-rental-system/issues/5) — лише індекс, його закриття не є GO. Усі Gate очікують рішення людини. Планова прив’язка не означає реалізацію, успішне тестування, прийняття або GO.
