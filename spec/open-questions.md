# Реєстр уточнень вимог

Актуалізовано 30 жовтня 2026 року. Попереднє твердження «невирішених питань немає» не є актуальним статусом усіх зауважень огляду. Порядок уточнень — [CP-01/CP-02](../planning/revised-decomposition.md).

| Питання | Статус | Рішення / зв’язки |
| --- | --- | --- |
| Q-07: проміжні календарні межі й 90-денний горизонт | Закрито за погодженням користувача | [ADD-001 §2–§4](srs-addendum-001.md); REQ-F-028–REQ-F-036; AC-F-032-02, AC-F-033-02, AC-F-034-02, AC-F-035-02–AC-F-035-04, AC-F-036-02; BDD-019–BDD-020 |
| Q-11: строк сесії (раніше ненумероване питання API) | Закрито за погодженням користувача | [ADD-001 §1](srs-addendum-001.md); REQ-F-093–REQ-F-094; AC-F-093-01–AC-F-094-01; BDD-017 |
| Q-12: зміна пароля й чинні сесії (раніше ненумероване питання API) | Закрито за погодженням користувача | [ADD-001 §1](srs-addendum-001.md); REQ-F-095–REQ-F-096; AC-F-095-01–AC-F-096-01; BDD-018 |
| Q-09: критерій стійкості хешування | Погоджено користувачем 30.10.2026 | Argon2id: 19 MiB, 2 ітерації, паралельність 1, окрема випадкова сіль; [рішення](../logs/tdd/implementation-decisions.md). Це не прийняття реалізації |
| Q-08: приймальний сценарій відновлення | Залишено відкритим користувачем 30.10.2026 | [Рішення](../logs/tdd/implementation-decisions.md); backup-діагностика не підтверджує NF-008/009 |
| Q-10: методика продуктивності | Залишається відкритою | SRS §5, REQ-NF-001–REQ-NF-004; немає погоджених вибірки/тривалості/профілю браузерного навантаження |

Q-11/Q-12 продовжують нумерацію Q-01–Q-10, не змінюючи попередніх ID. Інші питання CP-01 не оголошуються закритими цим рішенням; їх статус визначають відповідні погодження. Закриття вимог не означає проходження Gate, реалізації чи приймального тестування. Глобальну матрицю для пункту 16 не змінено.
