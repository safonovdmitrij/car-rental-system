# Історичний стан перед пунктом 16

Збережено матрицю, технічний огляд API-GATE та його маніфест до оновлення глобальної простежуваності. Вкладені шляхи spec/ і api/ відповідають шляхам у маніфесті.

Хеші старої матриці та api-gate.md у маніфесті перевіряються проти цих знімків; решта 27 джерел не змінювалися в пункті 16. Маніфест у корені api/ залишено незмінним як доказ попереднього огляду. Старі згадки відкладеної матриці всередині знімків є історичним вмістом.

Актуальні документи: [матриця](../../../spec/traceability-matrix.md) та [API-GATE](../../api-gate.md). Людське затвердження Gate не надано; це архів документів, не нове рішення.
