# Конвенція повідомлень комітів

Формат повідомлення: 

`<префікс>: <короткий опис зміни>`

Префікси: 

 - `spec:` - створення або зміна вимог і специфікацій.
 - `test:` - створення або зміна тестів. 
 - `feat:` - реалізація функціональності системи.
 - `docs:` - зміна документації та журналів.
 - `gate:` - фіксація результатів перевірки або завершення етапу SDD.
